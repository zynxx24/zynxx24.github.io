SquidWings

An open-source AI agent for the terminal and the browser, in Bahasa Indonesia. It works with any OpenAI-compatible model, including Claude, GPT, Gemini, DeepSeek and local models through Ollama.

CateringKu

Laravel 13 · Vue 3 · Inertia · Tailwind

A catering marketplace with separate customer, vendor and admin roles. Prices and promo codes are calculated on the server, checkout runs in a database transaction, and 72 Pest tests cover carts, checkout and access control.

Source and screenshots

Class cash, three ways

Kotlin · Jetpack Compose · works offline

Three Android apps for the XII PPLG class cash, each built with a different group: weekly dues, late fines, payment history and reports. Only the treasurer can mark a payment as paid; students send a WhatsApp confirmation from the app.
