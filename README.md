# zynxx24.github.io

Source of [zynxx24.github.io](https://zynxx24.github.io/), the home page that links all my projects. One static `index.html`, no build step.

Also holds the domain-wide `robots.txt` and `sitemap.xml`, which point search engines at the project sites under `zynxx24.github.io/<repo>/`.

Fonts: Unbounded and Space Grotesk, SIL Open Font License 1.1 (see `assets/fonts/README.md`).
